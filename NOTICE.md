Test-only adapter decodes original base64 fields, converts null paths to empty
arrays and invokes digest-level verification. Expected digests and outcomes
remain those in the pinned originals; no expected values generated by this lab.
Product schema uses raw leaf bytes encoded as lowercase hex and requires []
instead of null paths. Original files are never modified during adaptation.
